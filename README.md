# MATMUH Data & AI
 
A student community for Mathematical Engineering students to learn data science and machine learning from the ground up and to build projects together.
 
## Goal
 
Bring students together, give them perspective and a solid theoretical grasp of data science and machine learning, and turn that into real projects that are built and shared openly on GitHub.
 
## Who is it for?
 
Everyone. No prior experience is required, and taking part in a project is optional.
